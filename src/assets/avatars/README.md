# 角色立绘

这里放的图一进来就自动生效，不用改代码。一张都不放也能跑 ——
那时候用的是 `src/components/Avatar.tsx` 里的 SVG 手绘版。

现在这十张是从 `design/avatar-board.png`（设计稿原图）切出来的，
切图参数写在下面，原图留在 `design/` 里没进 `src/` ——
它有 2MB，放进 `src/` 会被打包并塞进 Service Worker 的离线缓存。

## 文件名

必须是 `<性别>-<阶段>.<后缀>`，性别是 `m` / `f`，后缀支持 webp / png / jpg。

| 文件            | 阶段               | 从哪个段位开始       |
| --------------- | ------------------ | -------------------- |
| `m-rookie.webp` | Lv.1 新手 Rookie   | Herald（MMR 0）      |
| `m-player.webp` | Lv.10 进阶 Player  | Guardian（MMR 100）  |
| `m-elite.webp`  | Lv.30 精英 Elite   | Archon（MMR 300）    |
| `m-pro.webp`    | Lv.50 高手 Pro     | Ancient（MMR 700）   |
| `m-legend.webp` | Lv.100 传奇 Legend | Immortal（MMR 1000） |

女生版同理，把 `m-` 换成 `f-`。少放几张也能跑，缺的那几个阶段自动退回 SVG。

## 图片要求

- **竖构图、全身**，高 768，宽按比例。头像圆圈是按这个构图裁的，
  构图差太多就去调 `src/lib/avatarArt.ts` 里的 `HEAD_CROP`。
- **单张 40KB 以内**。这是离线优先的 App，十张图会整个打进
  Service Worker 的预缓存（`vite.config.ts` 的 `globPatterns` 要带上后缀名，
  漏了的话离线时头像会变成空白）。
- 背景可以带也可以透明。现在这批是连设计稿的渐变底一起切下来的 ——
  那个底色本来就是按等级配的（蓝 → 紫 → 金），留着比抠掉好看，
  抠图还会在边缘留一圈杂色。

## 切图参数

设计稿 1254×1254，五张卡的分界线在 x = 183 / 377 / 565 / 767 / 985 / 1232。
卡片之间那个 `»` 箭头压在分界线上、几乎整个落在右边那张卡里
（实测 383-398 / 564-587 / 764-788 / 977-1006），所以左边要多收 26px，
第一张不用。上下：男 y 192-636，女 y 770-1186。

## 为什么阶段不是等距的

段位一共八段，形象只有五个，所以是 1 / 2 / 2 / 2 / 1 分的：
先锋 → 卫士·中军 → 统帅·传奇 → 万古·超凡 → 冠绝。
对应关系写在 `src/lib/avatarArt.ts` 的 `STAGES`，要改改那里一处就够。

## 有立绘之后金币花在哪

立绘是一整张画好的人，没法把发型／战服／球拍单独换掉，
所以这三类在有立绘的时候会从商店和衣柜里收起来
（`slotIsDressable`），肤色同理。金币改成花在画在人外面的东西上：
背景、头像框、称号。

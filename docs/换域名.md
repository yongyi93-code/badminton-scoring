# 换域名到 rallybadminton.com

一次性的操作，做完就不要再做第二次 —— 换域名 = 换 origin，所有人已装的
App、登录状态、本机缓存全部重来。8 个人的时候是一条 WhatsApp 消息，
1000 个人的时候是灾难。

## 顺序不能反

CNAME 一旦生效，GitHub Pages 会把 `yongyi93-code.github.io/badminton-scoring`
**重定向**到新域名。所以 DNS 没配好就先合 CNAME，等于网站直接打不开。

    1. 先配 DNS      ← 你，在 Exabytes 后台
    2. 等它生效       ← 查一下，别猜
    3. 再合 CNAME     ← 合并这个分支到 main
    4. 等 HTTPS 证书  ← GitHub 自动签，最长 24 小时
    5. 全员重装验证    ← 球群 8 个人

挑一个**没有球局的晚上**做。证书签发期间网站可能短暂打不开。

---

## 1. DNS 记录（Exabytes 后台）

登录 → My Domains → rallybadminton.com → DNS Management。

### 必填：4 条 A 记录

把 `@`（根域名）指向 GitHub Pages 的四个地址：

| 类型 | 名称 | 值 |
|------|------|-----|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

四条都要加。GitHub 用它们做负载均衡和故障转移，只加一条哪天那台出问题
网站就没了。

> 这四个地址不是抄文档抄来的，是 `github.io` 自己解析出来的实测值。

### 选填：www

想让 `www.rallybadminton.com` 也能进，加一条：

| 类型 | 名称 | 值 |
|------|------|-----|
| CNAME | www | yongyi93-code.github.io |

不加也行，只是别人输 www 会进不去。

### 别加的

- **AAAA（IPv6）**：可加可不加，加错了反而麻烦。IPv4 四条够用。
- **别动 MX / TXT**：那些是邮件和域名验证用的，删了会出事。

---

## 2. 确认 DNS 生效了再往下

Exabytes 后台显示「已保存」不等于生效。自己查：

```
nslookup rallybadminton.com
```

四个 185.199.x.153 都出来了，才算好。**通常几分钟到几小时，最长 48 小时。**

没出来就等，别急着做第 3 步。

---

## 3. 合并这个分支，然后手动填一次域名

合到 `main` 之后 Actions 自动部署。部署完去仓库 **Settings → Pages**。

### ⚠️ Custom domain 那一栏会是空的，要自己填

这里踩过：本项目的 Source 是 **GitHub Actions**，不是 "Deploy from a
branch"。**Actions 模式下，打包产物里的 CNAME 文件不会自动写进这个
设置** —— 那是分支部署模式才有的行为。

所以第一次必须手动：在 Custom domain 框里填 `rallybadminton.com`，
按 **Save**。这一下才会触发 GitHub 去做 DNS 检查、去申请证书。

那 `public/CNAME` 还留着干嘛？留着是为了**以后每次部署不会把这个设置
冲掉**。两个都要有：文件保住它，手动填一次点着它。

填完之后：

- 下面会出现 DNS check / 证书申请中的提示
- **Enforce HTTPS** 这时是灰的、点不了
- 证书签好了那个勾才能点 —— **记得回来勾上**

---

## 4. 等 HTTPS 证书

GitHub 自动签 Let's Encrypt 证书，**最长 24 小时**。

这期间可能看到「证书不匹配」的警告，是正常的。等 Settings → Pages 那里
不再显示黄色提示，Enforce HTTPS 能勾上，就好了。

---

## 5. 全员重装

换域名 = 换 origin。浏览器按 origin 隔离 localStorage、Service Worker、
登录状态，所以：

- **已装的 App 图标要删掉重装** —— 旧的还指向 github.io
- **要重新登录一次**
- **数据不会丢** —— 云端是真相，登录后会拉回来

在球群里发一条：

> RALLY 换新网址了：https://rallybadminton.com
> 麻烦把桌面上旧的图标删掉，从新网址重新装一次、重新登录。
> 战绩和角色都在云端，不会丢。

**自己先在一台手机上走完整个流程再发群** —— 确认登录进去战绩还在。

---

## 万一要回滚

删掉 `public/CNAME`，合到 main 重新部署，Settings → Pages 里清空
Custom domain。旧地址会恢复。已经按新域名装过的人要再重装一次 ——
所以能不回滚就不回滚，第 2 步多等一会儿比回滚便宜。

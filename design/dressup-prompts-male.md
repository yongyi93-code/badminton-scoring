# 男生换装素材出图指令（豆包）

一共要 **45 张**：1 张底图 + 44 张变体（上衣／下装／球鞋／球拍 各 11 件）。

出完之后放进 `design/dressup-src-male/`，跑一条命令就能拆成分层素材：

```bash
python3 design/extract-dressup.py design/dressup-src-male src/assets/dressup-m
```

---

## 一、先看这四条，比画得好看重要

拆分层的原理是**拿变体和底图逐像素比对，不一样的那块就是那件装备**。所以：

1. **每张只能改一处，其余必须一模一样。**
   头、脸、发型、站姿、手的位置、背景绿——全都不能动。
   → 所以变体**必须用「局部重绘 / 涂抹修改」在底图上改**，不能重新生成一张。
   重新生成 = 45 个不同的人，一张都用不了。

2. **背景必须是纯绿幕，45 张同一个绿。**
   建议 `#2C946A`（偏青的中绿，和女生那套一样）。
   绿幕有两个用处：一是白衣服白球鞋能被抠出来，二是人物能从背景里扣干净，才能衬 App 里买来的背景。

3. **45 张尺寸必须完全相同。** 比例 3:4，用豆包最大的那档（2K，出来大约 1728×2304）。中途不要换尺寸档位。

4. **不要地面阴影、不要文字水印签名、不要装饰边框。** 这些会混进差异区域里被当成装备抠出来。

出完每一张，**先和底图肉眼比一眼**：头、手、站姿、绿色有没有变。变了就重做——这一步偷懒，后面拆出来的图层会整体错位。

每次都带上这句固定尾巴（防止它顺手改别的）：

```
只改这一处，人物的脸、发型、姿势、身体比例和背景绿全部保持原样不变。
背景仍是纯色绿幕 #2C946A，不要阴影、不要文字水印。
```

## 四、出完之后

1. 45 张全部命名对（`base.png` / `top-01.png` … `racket-11.png`），放进 `design/dressup-src-male/`
2. 告诉我一声，我跑拆分层的脚本，把男生这四个槽位接进商店

拆的时候脚本会打印每一件的位置和实心占比。**某一件占比特别低、或者位置框大得离谱**，就是那张改动带跑偏了（多半是姿势或背景变了），单独重做那一张就行，不用全部重来。

# 羽球记分

给球友群用的羽毛球记分 App。到球馆后开一个「球局」，勾选今晚到场的人，App 负责公平排场、记分、算排名、分摊费用，散场时生成一张战绩图发到群里。

手机网页 App（PWA）—— 加到主屏幕后跟原生 app 一样用，**离线可用，数据存在手机本地，不需要账号、不需要后端**。

## 装到手机上

**https://yongyi93-code.github.io/badminton-scoring/**

- **iPhone**：用 **Safari** 打开上面的网址 → 底部「分享」→ 往下滑找到 **「添加到主屏幕」**。必须是 Safari，iOS 上的 Chrome 装不了。
- **Android**：用 Chrome 打开 → 右上角菜单 → **「安装应用」**。

装完开飞行模式点一次图标验证：能打开就说明缓存好了，球馆没网也能用。

### iPhone 上的三个注意点

1. **把自动锁屏调长。** iOS 不支持网页控制屏幕常亮，记分时屏幕会自己黑掉。设置 → 显示与亮度 → 自动锁定 → 5 分钟或永不。
2. **只从主屏幕图标进，别在 Safari 里另开。** iOS 上主屏幕 app 和 Safari 的存储可能是分开的，混着用会看到两份不同的数据。
3. **每次打完球导出一次备份。** 首页最下面「数据备份与恢复」→ 导出。iOS 会清理长期不用的网页存储，这是唯一的保险。

## 本地开发

```bash
npm install
npm run dev -- --host
```

终端会打印一个局域网地址（形如 `http://192.168.x.x:5173`），手机连同一个 wifi 就能打开。

注意局域网是 `http://`，不是安全上下文，**Service Worker 不可用，所以没有离线功能** —— 只适合开发时试功能，正式用请装上面那个网址。

## 发布新版本

推到 `main` 就会自动构建并发布（`.github/workflows/deploy.yml`）。测试不过不会发布。

```bash
git push
```

网址固定不变。**不要换到别的域名或路径** —— 数据是按网址（origin）存在手机本地的，换网址等于换了一个 app，之前的记录读不到。

## 它解决什么

| 痛点 | App 怎么做 |
| --- | --- |
| 有人连坐冷板凳 | 「已打场数最少的人必须上场」是**硬约束**，不是罚分。等待区按该谁上场排序，每人显示已打几场、休息了几轮 |
| 同一对搭档反复凑一起 | 近 3 场同队过的组合重罚，对手重复也罚 |
| 高手扎堆打菜鸟 | 按球员水平（1–5 星）罚两队水平和的差值 |
| 双打老是吵谁该发球、站哪边 | 记分屏画出四人当前站位，标出发球者（🏸）和接发球者，规则完整实现：发球方得分才换左右区 |
| 散场吵谁最强 | 胜率 → 净分差 → 场数排名，不足 3 场不上榜，自动评今晚 MVP |
| 群主每次手算 AA | 场地费 + 球钱 ÷ 人数，向上取整到 0.5，谁付了打个勾 |

## 三种打法模式

开局时选，看板上随时能看到「还剩几场」。**到点只提示，不会自动结束球局** —— 自动结束会吞掉正在打的比分。

| 模式 | 怎么排场 | 什么时候结束 |
| --- | --- | --- |
| **自由模式** | 公平轮转配对，边打边排 | 打满几场 / 打多久 / 每人打满几场，都可留空表示不限 |
| **车轮赛**（打上打落） | 赢的两人留场，输的两人排队尾，队头两人组队上来挑战 | 同上。连赢 N 场（默认 3）强制下场休息，防止高手霸场一整晚 |
| **轮转赛**（X 人转） | 开局一次排好整份赛程，每人场数均等、搭档尽量不重复 | 赛程打完自动提示结算，也可以「再排 4 场」加时 |

几个细节：

- **轮转赛按实到人数生成**，不限 6/8/12 人 —— 7 人、9 人、13 人都能用。开局前就显示「8 人 · 2 片场 · 每人 6 场 · 共 12 场」。
- **中途有人走 / 有人晚到**：改完出席名单点「按现在的人重排」，只重排还没打的，已打完的一场都不动。
- **设了时长**会按实际节奏估算「剩下的时间还够打几场」，按小时租场时很有用。
- **「每人至少打 N 场」是下限不是上限**：时间到了但有人没打够，会提示「还有 2 人没打满 6 场」，加不加时你自己决定。

## 分场馆排行榜

累计排行榜可以按球馆分开看 —— 每个场馆有自己独立的名次和「本馆之王」，挑战者一眼就知道该找谁。

- 排行榜顶部有场馆切换：**全部场馆 / 城中羽球馆 / 北区体育馆 …**，选中某个场馆后会显示 👑「XX馆之王」
- 同一个人在不同场馆可以是完全不同的名次（在主场全胜、在客场垫底）
- 散场结算页和**战绩分享图**都会带上「本馆累计第一」，发到群里大家就知道现在谁在守擂

**球馆名会自动归组**：「城中羽球馆」「城中 羽球馆」「 城中羽球馆 」算同一个场馆，英文名也不分大小写 —— 不然打字差一个空格排行榜就被拆成两个。开局时还会列出你用过的球馆让你直接点选，尽量别再手打。

## 功能

- **球局**：日期 / 球馆 / 场地数 / 赛制（双打、单打、混双）/ 计分规则（11、15、21 分；净胜 2 分；一局或三局两胜）
- **场地看板**：每片场的实时比分，空场一键排下一场，也可以先预排让大家知道下一场是谁
- **人工干预**：整场重排、单个换人、指定某人「下一场必上」、临时标记某人休息
- **记分**：实时点分（大按钮 + 发球提示 + 撤销）**或**直接输最终比分；记分时屏幕保持常亮；场地时间到了可以「提前结束这一场」按当前比分算
- **排行榜**：今晚榜 + 累计榜
- **个人档案**：总场数、胜率、净分差、最长连胜、最佳搭档、苦主、最近 20 场
- **结算**：今晚 MVP、排名、AA 费用、一键生成战绩图（走系统分享面板，可直接发进 WhatsApp / 微信群）
- **备份**：导出 / 导入 JSON

## 代码结构

核心算法都是纯函数，单独测试（122 个用例）：

| 文件 | 职责 |
| --- | --- |
| `src/lib/rotation.ts` | 公平轮转配对。硬性公平 + 搭档/对手多样性 + 实力平衡 + 混双性别约束 |
| `src/lib/sessionFormat.ts` | 三种打法模式。轮转赛赛程生成、车轮赛排队与连胜判定、进度与结束条件 |
| `src/lib/venues.ts` | 按球馆分组。归组 key 与显示名分离，避免空格/大小写把同一个场馆拆散 |
| `src/lib/scoring.ts` | 羽球规则。局点判定、封顶分、发球方与左右场区推导、撤销 |
| `src/lib/ranking.ts` | 由比赛记录实时推导统计与排名（不落库，避免和实际战绩对不上） |
| `src/lib/fee.ts` | 费用分摊 |
| `src/store/useApp.ts` | zustand + persist，全部数据存 localStorage |
| `src/screens/` | 八个屏：首页、球员库、开局、场地看板、记分、排行榜、结算、个人档案 |

发球推导值得说明：羽球双打里球员**只有在本方发球且得分时才交换左右区**，所以站位无法只靠分数奇偶推出来。实现方式是记下每一局的开局站位 + 逐分记录（谁拿下每一分），需要时从头推演一遍。好处是撤销变成「去掉最后一分」，且发球状态永远和比分一致。测试里用 200 组随机逐分序列校验不变式：**发球者永远是发球方站在发球区的那个人**。

## 已知取舍

- **数据只在记分那台手机上。** 清掉浏览器数据或换手机就会丢 —— 首页有「数据备份与恢复」，建议每次打完球导出一次。
- 多人各自查看、实时同步需要后端和账号，v1 不做。
- 混双依赖球员的性别字段，没填性别的人不会被自动排进混双（界面会提示）。
- 屏幕常亮用 Wake Lock API，iOS Safari 目前不支持，会静默跳过。
